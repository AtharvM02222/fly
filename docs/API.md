## Authentication

Drone-CDS uses two authentication methods:

### 1. JWT for Dashboard Users

Used by dashboard/web clients. Obtained via `/auth/login`.

```http
Authorization: Bearer <jwt_token>
```

### 2. API Keys for Edge Devices

Used by edge detection devices. Generated by admins via dashboard or CLI.

```http
X-API-Key: <device_api_key>
```

## Endpoints

### Authentication Endpoints

#### POST /auth/login

Authenticate dashboard user and obtain JWT token.

**Request:**
```json
{
  "email": "admin@example.com",
  "password": "your-password"
}
```

**Response:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "user": {
    "id": "uuid",
    "email": "admin@example.com",
    "role": "admin",
    "created_at": "2026-09-21T10:00:00Z"
  }
}
```

**Errors:**
- `401 Unauthorized` - Invalid credentials
- `422 Unprocessable Entity` - Validation error

### Detections

#### POST /detections

Ingest detection batch from edge device. Idempotent on `client_detection_id`.

**Authentication:** API Key (device)

**Request:**
```json
{
  "detections": [
    {
      "client_detection_id": "uuid",
      "latitude": 37.7749,
      "longitude": -122.4194,
      "severity": "high",
      "confidence": 0.87,
      "bbox": {
        "x1": 100,
        "y1": 150,
        "x2": 300,
        "y2": 350
      },
      "model_version": "v1.0",
      "detected_at": "2026-09-21T10:30:00Z",
      "is_interpolated": false
    }
  ]
}
```

**Response:**
```json
{
  "results": [
    {
      "client_detection_id": "uuid",
      "status": "created",
      "detection_id": "server-uuid"
    }
  ]
}
```

**Status codes:**
- `created` - New detection created
- `existing` - Detection with this client_detection_id already exists
- `error` - Failed to process (see details)

**Errors:**
- `401 Unauthorized` - Invalid API key
- `422 Unprocessable Entity` - Validation error
- `429 Too Many Requests` - Rate limit exceeded

---

#### GET /detections

List detections with filters and pagination.

**Authentication:** JWT

**Query Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `min_lat` | float | Minimum latitude (bbox filter) |
| `max_lat` | float | Maximum latitude (bbox filter) |
| `min_lon` | float | Minimum longitude (bbox filter) |
| `max_lon` | float | Maximum longitude (bbox filter) |
| `status` | string | Filter by status: `new`, `confirmed`, `assigned`, `fixed`, `verified` |
| `severity` | string | Filter by severity: `low`, `medium`, `high` |
| `device_id` | uuid | Filter by device |
| `start_date` | ISO8601 | Filter by detected_at >= start_date |
| `end_date` | ISO8601 | Filter by detected_at <= end_date |
| `page` | integer | Page number (default: 1) |
| `page_size` | integer | Results per page (default: 50, max: 1000) |

**Response:**
```json
{
  "items": [
    {
      "id": "uuid",
      "client_detection_id": "uuid",
      "device_id": "uuid",
      "latitude": 37.7749,
      "longitude": -122.4194,
      "geohash": "9q8yy",
      "severity": "high",
      "confidence": 0.87,
      "status": "new",
      "image_url": "https://storage/detections/uuid.jpg",
      "bbox": { "x1": 100, "y1": 150, "x2": 300, "y2": 350 },
      "model_version": "v1.0",
      "detected_at": "2026-09-21T10:30:00Z",
      "created_at": "2026-09-21T10:30:05Z",
      "merged_into": null
    }
  ],
  "total": 142,
  "page": 1,
  "page_size": 50,
  "pages": 3
}
```

**Errors:**
- `401 Unauthorized` - Not authenticated
- `422 Unprocessable Entity` - Invalid filter parameters

#### PATCH /detections/{id}

Update detection status (creates audit event).

**Authentication:** JWT (operator+ role required)

**Request:**
```json
{
  "status": "fixed",
  "note": "Repaired by crew on 2026-09-21"
}
```

**Response:**
```json
{
  "id": "uuid",
  "status": "fixed",
  ... (full detection object)
}
```

**Valid Status Transitions:**
- `new` → `confirmed`, `assigned`, `fixed`
- `confirmed` → `assigned`, `fixed`
- `assigned` → `fixed`
- `fixed` → `verified`

**Errors:**
- `401 Unauthorized` - Not authenticated
- `403 Forbidden` - Insufficient permissions (viewer role)
- `404 Not Found` - Detection doesn't exist
- `422 Unprocessable Entity` - Invalid status transition

## Error Handling

All errors follow a consistent format:

```json
{
  "error_code": "VALIDATION_ERROR",
  "message": "Validation failed",
  "details": {
    "field": "email",
    "issue": "Invalid email format"
  }
}
```

### Common Error Codes

| Code | HTTP Status | Description |
|------|-------------|-------------|
| `VALIDATION_ERROR` | 422 | Request validation failed |
| `AUTHENTICATION_ERROR` | 401 | Invalid or missing credentials |
| `AUTHORIZATION_ERROR` | 403 | Insufficient permissions |
| `NOT_FOUND` | 404 | Resource doesn't exist |
| `RATE_LIMIT_EXCEEDED` | 429 | Too many requests |
| `INTERNAL_ERROR` | 500 | Server error |

## Rate Limiting

### Edge Device Ingest

- **Limit:** 100 requests per minute per device
- **Header:** `X-RateLimit-Limit: 100`
- **Remaining:** `X-RateLimit-Remaining: 87`
- **Reset:** `X-RateLimit-Reset: 1695288600`

### Dashboard API

- **Limit:** 1000 requests per minute per user
- **Header:** Same as above

When rate limit exceeded:
```json
{
  "error_code": "RATE_LIMIT_EXCEEDED",
  "message": "Rate limit exceeded. Try again in 42 seconds.",
  "details": {
    "retry_after": 42
  }
}
```

## Code Examples

### Python (Edge Device)

```python
import requests

API_URL = "http://backend:8000/api/v1"
API_KEY = "dcs_live_abc123..."

headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
}

detections = [
    {
        "client_detection_id": "uuid-from-edge",
        "latitude": 37.7749,
        "longitude": -122.4194,
        "severity": "high",
        "confidence": 0.87,
        "bbox": {"x1": 100, "y1": 150, "x2": 300, "y2": 350},
        "model_version": "v1.0",
        "detected_at": "2026-09-21T10:30:00Z",
        "is_interpolated": False
    }
]

response = requests.post(
    f"{API_URL}/detections",
    json={"detections": detections},
    headers=headers
)

print(response.json())
```

### JavaScript (Dashboard)

```javascript
const API_URL = "http://localhost:8000/api/v1";
const token = localStorage.getItem("auth_token");

const response = await fetch(`${API_URL}/detections?status=new&severity=high`, {
  headers: {
    "Authorization": `Bearer ${token}`,
    "Content-Type": "application/json"
  }
});

const data = await response.json();
console.log(data.items);
```
