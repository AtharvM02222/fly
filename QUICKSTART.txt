DRONE-CDS QUICKSTART
====================

GET RUNNING IN 5 MINUTES
-------------------------

1. CLONE AND SETUP
   
   cd drone-cds
   cp .env.example .env
   
   Edit .env and set:
   - POSTGRES_PASSWORD
   - SECRET_KEY (generate with: openssl rand -hex 32)
   - ADMIN_PASSWORD

2. START SERVICES
   
   ./deploy.sh development
   
   This starts:
   - PostgreSQL with PostGIS
   - Backend API on port 8000
   - Dashboard on port 3000

3. VERIFY DEPLOYMENT
   
   ./test_system.sh
   
   All checks should pass.

4. ACCESS DASHBOARD
   
   Open: http://localhost:3000
   Login: admin@dronecds.local / <your ADMIN_PASSWORD>

5. CREATE A DEVICE
   
   Option A - Via API:
   
   curl -X POST http://localhost:8000/api/v1/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"admin@dronecds.local","password":"changeme123"}' \
     | jq -r '.access_token' > token.txt
   
   curl -X POST http://localhost:8000/api/v1/devices \
     -H "Authorization: Bearer $(cat token.txt)" \
     -H "Content-Type: application/json" \
     -d '{"name":"test-drone","device_type":"drone"}' \
     | jq .
   
   Save the device ID and API key.
   
   Option B - Via script:
   
   docker-compose exec backend python -m app.scripts.create_device \
     --name test-drone --type drone

6. RUN EDGE DEVICE (MOCK MODE)
   
   cd edge
   pip install -r requirements.txt
   
   Update config/default.yaml:
   - Set device.device_id to your device UUID
   - Set device.api_key to your device API key
   
   python main.py --detector mock
   
   Synthetic detections will appear in dashboard.

COMMON COMMANDS
---------------

Start services:
   docker-compose up -d

Stop services:
   docker-compose down

View logs:
   docker-compose logs -f backend
   docker-compose logs -f dashboard

Database shell:
   docker-compose exec postgres psql -U dronecds

Create admin user:
   docker-compose exec backend python -m app.scripts.create_admin \
     --email admin@example.com --password secure123

Create device:
   docker-compose exec backend python -m app.scripts.create_device \
     --name my-device --type drone

Run migrations:
   docker-compose exec backend alembic upgrade head

Export detections:
   curl "http://localhost:8000/api/v1/reports/export?format=csv" \
     -H "Authorization: Bearer $(cat token.txt)" \
     -o export.csv

TROUBLESHOOTING
---------------

Backend won't start:
   - Check .env file exists
   - Verify PostgreSQL is running: docker-compose ps
   - Check logs: docker-compose logs backend

Dashboard shows error:
   - Verify backend is running: curl http://localhost:8000/healthz
   - Check browser console for errors
   - Verify NEXT_PUBLIC_API_URL in dashboard/.env.local

Edge device errors:
   - Start with --detector mock to isolate model issues
   - Check API key is correct
   - Verify backend URL in config
   - Test camera: ls /dev/video*

No detections appearing:
   - Check edge device logs
   - Verify device is created in backend
   - Check API key is valid
   - Test with mock detector first
